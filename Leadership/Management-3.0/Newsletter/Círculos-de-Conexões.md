# Uma nova prática: Connection Circles X Stakeholder Mapping

Mas então, como a felicidade está afetando a produtividade na sua organização? O que acontece se você, como líder de equipe, microgerenciar as coisas? Descubra quais elementos em um sistema adaptativo complexo se reforçam desenhando um Círculo de Conexão.

### POR QUE USAR O "CÍRCULOS DE CONEXÃO"?

- Permite que você entenda a complexidade vendo causas e efeitos no sistema.
- Ajudá-lo a encontrar as causas dos problemas e não se concentrar nos sintomas.
- Fornecer informações sobre qual relacionamento você precisa alterar para obter um comportamento diferente no sistema.
- Ajudá-lo a identificar loops de feedback.
- Inicia a discussão e a conversa em um sistema.

### Exercício

1. Crie um círculo.

2. Identifique os elementos-chave do sistema que você está examinando. O elemento-chave deve atender a esses critérios? A ideia é identificar ou darmos nomes as partes imprescindíveis do sistema. Um substantivo pode descrevê-lo.

3. Escreva esses elementos ao redor do círculo (no máximos 10).

4. O próximo passo é procurar causa e efeito:
- Quais elementos estão diretamente causando o aumento ou diminuição de outros elementos? Desenhe uma seta entre esses elementos.
- Indique um aumento (desenhar “+”) ou uma diminuição (desenhar “–”) para o segundo elemento em cada relação.
- Encontre todas as relações de causa e efeito. Estes podem ser baseados em dados ou podem ser uma hipótese.
- Procure elementos cujas relações formam loops fechados. Estes são ciclos de feedback.
