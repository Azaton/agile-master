1. Criação de Bancos de Dados

Sequência do processo de criação de bancos de dados: Requisitos, Modelo, Arquitetura e Implementação.
O objetivo principal da modelagem de bancos de dados é fornecer um sistema capaz de atender às demandas dos usuários finais.

2. Atributos em Modelos ER

Tipos de atributos: Atômicos, Compostos, Multivalorados, Armazenados/Derivados, Nulos.
Atributos atômicos são indivisíveis, enquanto atributos compostos podem ser divididos em subpartes menores.
Atributos multivalorados podem ter mais de um valor para uma única entidade.
Atributos derivados são atributos cujo valor é calculado a partir de outros atributos.

3. Conjunto de Entidades

Uma entidade é uma coisa ou objeto do mundo real que é distinguível dos outros.
Um conjunto de entidades é um conjunto de entidades do mesmo tipo.
O esquema de uma entidade define a estrutura das entidades em um conjunto de entidades.

4. Entidades Fracas

As entidades fracas dependem de uma entidade principal para sua existência.
As entidades fracas têm chaves parciais que não são únicas em todo o conjunto de entidades.

5. Nomenclatura e Construtores do Esquema

Nomenclatura e construtores de esquema são usados para definir claramente e representar o esquema de banco de dados.
Eles ajudam a definir as entidades, atributos, e relacionamentos em um banco de dados.

6. Relacionamentos

Tipos de relacionamentos: Associação, Agregação, Relacionamento N-ário.
Associação binária é um relacionamento entre duas entidades.
Relacionamento N-ário envolve três ou mais entidades.

7. Cardinalidade e Restrições

Cardinalidade define o número de ocorrências em um relacionamento entre duas entidades.
Restrições são as regras aplicadas aos relacionamentos entre entidades.
