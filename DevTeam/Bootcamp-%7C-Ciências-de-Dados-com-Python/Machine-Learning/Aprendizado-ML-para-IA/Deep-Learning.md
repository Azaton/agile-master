**Deep Learning**

- **Definição**: É uma subcategoria de machine learning (ML) que se concentra em algoritmos inspirados na estrutura e função dos neurônios biológicos, chamados redes neurais artificiais. 
- **Características**: Em contraste com as redes neurais tradicionais que possuem poucas camadas, o deep learning utiliza redes neurais com muitas camadas (ou "profundas"), permitindo a modelagem de funções complexas e a detecção de características intrincadas em grandes conjuntos de dados.


**TensorFlow**

- **O que é**: O TensorFlow é um framework de código aberto desenvolvido pelo Google Brain Team, destinado a facilitar a construção, treinamento e implementação de modelos de deep learning.
- **Características**:
  - **Flexibilidade**: Pode ser usado para uma variedade de tarefas, não apenas para deep learning, mas também para tarefas de ML mais tradicionais.
  - **Escalar**: O TensorFlow pode ser executado em uma variedade de plataformas, desde dispositivos móveis até clusters de servidores.
  - **Ecossistema**: Possui uma ampla comunidade, o que resulta em muitos recursos de aprendizado, ferramentas complementares e extensões especializadas.
