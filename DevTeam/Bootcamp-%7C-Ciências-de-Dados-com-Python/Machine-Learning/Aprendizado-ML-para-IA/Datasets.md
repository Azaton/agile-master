Os datasets para aplicações relacionadas a percepção visual, detecção de obstáculos e sensoriamento geralmente envolvem combinações de imagens, dados de sensores e anotações. Especificamente, quando se fala sobre datasets para aplicações voltadas para pessoas com deficiência visual (como "cegos") e usando sensores como câmeras (exemplo: "bumblebee") e LiDARs (como "Velodyne"), a estrutura e foco podem variar.
