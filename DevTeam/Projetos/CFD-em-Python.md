# Objetivo

Entregar um MVP de Gráfico CFD (Cumulative Flow Diagram), que consulte os dados num Banco de Dados e faça a transposição dos dados para um front-end em Pyhton.

- [O que é CFD?](/Métricas-&-Indicadores-\(KPI\)/CFD-%2D-Cumulative-Flow-Diagram)
- [Sobre o projeto](/DevTeam/Projetos/CFD-em-Python/Projeto)
- [Estrutura no VS Code](/DevTeam/Projetos/CFD-em-Python/Arquitetura)


# Resultado Alcançado

O resultado foi um HTML rodando local. Foi possível consumir os dados de uma tabela no SQLite, passando 'import sqlit3' e transformando os dados em imagens.

O projeto foi organizado e documentado tecnicamente no Azure DevOps.
