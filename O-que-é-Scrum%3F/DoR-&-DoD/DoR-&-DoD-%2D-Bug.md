**DoR - Definition of Ready**

- Informar se é um bug de Homologação ou Produção.
- Classificar o "Tipo do Bug" usando os rótulos.
- Informar o incidente nos Bugs de Produção.
- Adicionar o bug a um PACK no JIRA.
- Anexar os logs para quando necessário analisar tecnicamente.
- Deve conter as evidências, descrição do erro e o resultado esperado.
- Ajustar o campo "Versões Corrigidas" com o trimestre de atuação.
