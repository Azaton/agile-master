Então o que é um MVP?

Olha só agora.

Perguntas essenciais aqui.

Foco total.

O que é um produto mínimo viável? É um produto que define o conjunto de features, funcionalidades

essenciais de um produto.

Então ele não é uma versão reduzida de um produto mas que entrega uma micro funcionalidade.

Ele tem que entregar uma camada essencial de funcionalidade para que seja usável.

Olha só é uma versão mais simples de um produto que agrega valor para o negócio e pode ser utilizado

e validado pelo usuário final.

Então ele tem que ser realmente usável.

Então ele é uma abordagem incremental para a construção do produto por meio de pequenas validações ao

longo do tempo então o foco do MVP é a gente definir métricas.

Principalmente da perspectiva de negócio para a gente conseguir fazer essa validação de forma incremental

do produto.

Então a gente define um conjunto mínimo de features, de funcionalidades e a gente foca para desenvolver

somente realmente o essencial.

E então a gente fala assim a gente define o MVP e os seus incrementos.

Então não é MVP 1 MVP 2 MVP 3. É o primeiro e único MVP e a partir dali você testa com o usuário pega feedback

com base no feedback você vai e você vai dizer o incremento é claro dependendo do feedback você vai

fazer adaptações ou até pivotar o MVP. Pivotar é um termo que

é como se fosse quase jogar fora o MVP e fazer outro zero, mudando o direcionamento estratégico

do seu do seu produto mínimo viável.

Então beleza agora qual é a segunda dúvida comum aqui olha só quais são as principais características

de um MVP?
